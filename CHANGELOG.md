# Changelog

## v0.3.1-(mod-0.0.10)

### 🛡️ Conflict Detection System (Система проверки конфликтов)
Реализована мощная система анализа правил на предмет конфликтов и дублей в реальном времени:
- **Duplicate Detection**: Мгновенное обнаружение полных дубликатов правил (Exact Match) как внутри одной группы, так и между разными группами
- **Hierarchical Conflicts**: Обнаружение логических перекрытий, когда одно правило перекрывает другое (например, `google.com` и `maps.google.com`, или пересекающиеся IP-диапазоны/CIDR).
- **Resolver UI**: Окно со списком конфликтующих правил и возможностью быстрого перехода к ним

## v0.3.1-(mod-0.0.9)

### 🔄 Updates (Обновления)
- **Updates from Web Interface**:

## v0.3.1-(mod-0.0.8)

### 📦 Rules Import System (Система импорта правил)
- **Lists Download**:
    - Возможность поиска и загрузки списков доменов популярных сервисов (Google, Telegram, Apple и др.) прямо в окне импорта
    - Интеграция с репозиторием `v2fly/domain-list-community`
    - Автоматическая загрузка содержимого выбранного списка правил
- **Advanced Rules Parsing**:
    - Умный разбор префиксов (`full:`, `domain:`, `regexp:`) при импорте
    - **Metadata Preservation**: Комментарии, атрибуты (`@attr`) и удаленные префиксы сохраняются в название правила для истории

### 🐛 Fixes & Improvements
- **Strict Domain Matching**:
    - Изменена логика работы Trie-дерева для правил типа `Domain`. Теперь они работают корректно как **строгое совпадение** (Exact Match). Ранее работало аналогично Namespace

## v0.3.0-(mod-0.0.4)

### ⚡ Performance (Производительность)
- **Group Rules Rendering**:
    - Реализована стратегия **Render-Once**: содержимое групп рендерится только при первом открытии. При сворачивании DOM-элементы не уничтожаются, а скрываются, что обеспечивает **мгновенное** повторное разворачивание групп без задержек

## v0.3.0-(mod-0.0.1)

### 🎉 Initial Mod Release
Первый релиз

### 🚀 Core Performance
- **Trie (Prefix Tree) Lookup**: Замена линейного перебора правил на префиксное дерево. Это обеспечивает мгновенный поиск маршрута даже при тысячах доменов
- **TrafficManager**: Более эффективная обработка трафика за счет проверки правил на соответствие по блокам: сначала все правила Namespace (с помощью Trie), затем Wildcard, а после уже Regexp выражения, а не последовательный перебор

### 🖥 Web UI Overhaul (Новый интерфейс)
Полная переработка веб-интерфейса для повышения удобства использования:

- **Tabbed Layout**: Интерфейс разделен на логические вкладки: `Группы`, `Интерфейсы`, `Настройки`
- **Advanced Group Management**:
    - **Mass Actions**: Поддержка множественного выделения (Shift/Ctrl) и массовых операций (удаление, перемещение, переключение состояния)
- **Interfaces**: Добавлено отображение детальной информации (ID, IP) на карточках интерфейсов
    - **Interface Shortcuts**: Возможность задавать псевдонимы для системных интерфейсов (например, `nwg0` -> `WireGuard - Нидерланды`)
- **Updates**: Система проверки и установки обновлений мода одной кнопкой прямо через веб-интерфейс
- **Integrated Tools**:
    - **Speedtest**: Встроенная утилита замера скорости с возможностью выбора конкретного интерфейса выхода
    - **Console Window**: Встроенный просмотр логов сервиса в реальном времени с возможностью изменения уровня логирования
    - **Service Control**: Кнопка перезагрузки сервиса прямо из UI
